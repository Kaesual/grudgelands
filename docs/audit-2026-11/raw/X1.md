### X1-D1 | Low | edge | grug_sounds.play sends a sound for a removed ObjectRef to every player, unpositioned

- **Where:** `mods/CORE/grug_sounds/init.lua:326-352`
- **What:** `target_key` treats anything with `get_pos` as an object; for a removed entity or a left player's stale ref, `is_player()` is false, so the call goes to `params.object = target`. The engine then leaves the sound `Local` and sends it to every connected client without a distance filter.
- **Evidence:** engine `src/script/common/c_content.cpp:1349-1357` (`object` is only applied when `ObjectRef::getobject` returns a live SAO; `src/script/lua_api/l_object.cpp:38-44` returns nullptr for a gone object); `src/server.cpp:2333-2370` (`Local`: `pos_exists` false equals `type != Local` false, every client is added, no `max_hear_distance` check).
- **Proposal:** return false at the top of `play` when `object and not target:is_valid()` (5.18 has `is_valid`, `l_object.cpp:3068`). Live targets unchanged.
- **Effort:** S · **Risk:** low · **Upgrade class (guess):** compatible
- **Confidence:** medium (engine path certain; how often a caller passes a removed ref is not proven)
