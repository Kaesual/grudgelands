## Findings (surprises)

1. **The castle suite's media is CC-BY-SA 3.0, not MIT.** `docs/research/assets/structures_decor.md` records "MIT / MIT" for all six mods. The repos say otherwise: `castle_masonry/textures/LICENSE.txt`, `castle_gates/textures/LICENSE.txt`, `castle_lighting/textures/LICENSE.txt`, `castle_storage/textures/LICENSE.txt` all name **Philipner / Napiophelios, CC-BY-SA 3.0**. Consequence: those textures stay BY-SA 3.0 with attribution + ShareAlike; they cannot be relabelled MIT. **Our research doc needs correcting.**
2. **`castle_tapestries/models/LICENSE.txt` is stale and wrong**: it declares "Stuart Jones - WTFPL" for `castle_crossbow_bolt_inv.png`, `_uv.png`, `_hit.png` — files that do not exist in this mod (they belong to castle_weapons). The three actual tapestry textures (64px) and the three `.obj` models are therefore **undocumented**; only the repo-level MIT covers them. Ask upstream or re-draw.
3. **`castle_shields` has no media licence file at all** — 20 shield PNGs + masks + `shield.svg` covered only by `README.md:5` "Licence: MIT". Usable, but record it as "MIT per README, no per-file list".
4. **`castle_tapestries` hard-depends on `unifieddyes`, which is GPL-2.0-only** (mt-mods/unifieddyes `LICENSE` = bare GPLv2 text, no "or later"). Do not vendor that dependency — reimplement the 256-colour picker or restrict tapestries to the `wool` palette.
5. **Natural Habitat: GPL-2.0-only in the repo vs GPL-2.0-or-later on ContentDB.** The repo `LICENSE` is the plain GPLv2 text and the string "any later version" appears nowhere else in the tree. Per AGENTS.md line 880 the repo wins → hard exclusion. It also ships **no media licence statement whatsoever**. Its own hard dependency `m7a` is GPL-3.0-or-later, which is inconsistent with GPLv2-only and suggests sloppiness rather than intent — worth one e-mail to Mish7913 before writing it off.
6. **Asuna contains AFL-1.1 code** (`mods/biomes` entirely, and a texture-credit block appended to `mods/farming/license.txt:225`, both "Copyright (C) 2021-2022: Atlante - AFL-1.1"). The FSF lists the Academic Free License (all versions through 3.0) as **GPL-incompatible**, so Asuna's own claim that "this game as a whole is released under GPLv3" is at least questionable for those files. Never take `asuna-mt/biomes`; if we take `farming`, take only TenPlus1's MIT part.
7. **Asuna is otherwise clean**: an automated scan of all 54 submodule licence files found no CC BY-NC and no CC BY-ND. The three "noncommercial" hits (beautiflowers, herbs, wielded_light) are the GPLv3 §6(c) boilerplate, not NC media.
8. **cottages has one unusable texture**: `cottages_rope.png` — "Bas080 (CC; see forum thread)" with no version or variant (`README.md`). Replace it. `cottages_slate.png` is CC-BY-SA **2.0/de** (a German-ported licence) — free, but a fourth licence version to track.
9. **cottages does not ship 9 of the textures it uses** (`README.md` end: `default_wood.png`, `default_tree.png`, `default_dirt.png`, `default_grass_side.png`, `default_chest_top/side/front.png`, `default_stick.png`, `farming_wheat.png`). Vendoring it without a `default`-equivalent texture set produces missing-texture nodes.
10. **nativevillages' sounds are the classic ContentDB-style trap**: `LICENSE` says "Animal Sounds + Environment are from freesound.org under Creative Commons License" with a list of usernames but no licence version per file. freesound serves CC0, CC BY *and* **CC BY-NC**. Treat the whole `sounds/` directory as unusable until each file is traced, exactly as the ambience-mod case in AGENTS.md line 882.
11. **Neither nativevillages nor pixelfurniture is findable on ContentDB under the obvious package ids** (`Skandarella/nativevillages`, `duckgo/pixelfurniture` both 404 via the API). No ContentDB metadata to cross-check — the repo files are the only source, and both are clean.
12. **castle_masonry has `depends =` empty** and cottages/x_farming/pixelfurniture likewise: four of our top picks are already game-agnostic and need only a material-table remap, not a `default` shim.
13. **nativevillages schematics are pure minetest_game.** Decoding all 42 `.mts` name-id tables gives exactly `default`(51) + `stairs`(17) + `doors`(12) + `wool`(8) + `beds`(4) + `flowers`(3) + `walls`(2) + `xpanes`(2) + `vessels`(1) + `bones`(1) + 17 own nodes — a single replacement table covers everything. Note the Y sizes are 34-56 because the buildings sit on top of a tall air/ground column (the `_30_` in the filename is the vertical offset).
14. **multidecor's 32-64px style is a real blocker, not a taste issue.** Placed next to castle_masonry/cottages/MTG 16px art it reads as a different game. Only ~10 of its 238 meshes are medieval-plausible at all.

## Recommended pick order for a village/capital building kit

1. **castle_masonry** — the structural backbone (walls, arrowslits, machicolations, pillars, roof slate, paving) with a `register_material{}` table that makes retargeting to `grug_*` a single patch, zero hard deps, 16px, and still maintained (2026-07-31). MIT code; budget CC-BY-SA 3.0 attribution for the textures.
2. **cottages** — the only source that covers village-tier *construction* rather than props: straw/reed/slate roofs, shutters, loam walls, the `feldweg` road mesh set, anvil/threshing/handmill. GPL-3.0-only combines fine with us; already dependency-free.
3. **minetest_game `doors` + `xpanes` + `beds` + `wool` + `dye`** — the mechanism layer every house needs (door/trapdoor/gate API, panes, beds, the 15-colour palette that castle_shields and any banner system build on), MIT code, already checked out and pinned.
4. **darkage** — best licence pair in the audit (MIT + CC0, no attribution debt at all) and 70 pre-industrial nodes: basalt, chalk, marble, slate, mud brick, adobe, reinforced wood, iron-bound glass — exactly the material variety that stops a capital looking monotone.
5. **xdecor-libre** — the interior-prop layer (barrel, table, chair, cushion, curtains, tatami, lanterns, paintings, stonepath, itemframe), 16px, CC0 textures with an explicit exception list, and Wuzzy-grade licence hygiene; needs an MTG shim.
6. **VoxeLibre `mcl_villages` schematics** — 12 tight, well-composed building footprints (tavern, church, library, blacksmith, butcher, farm, well, belltower, 3 house sizes) for the price of a node-replacement table and a CC BY-SA 4.0 credit to MysticTempest; the fastest route to "a village exists at all".
7. **nativevillages** — 42 more schematics in 6 cultural flavours plus 56 props/NPC meshes, MIT, and the schematics reference only minetest_game nodes. Discounted to #7 only for the unverified freesound sounds (drop them), the inconsistent 16/32/64/128px art, and being stale since 2023.
8. **castle_gates + castle_lighting + castle_storage + castle_shields** — the capital flair pass: portcullis and swinging gates, braziers and chandeliers, ironbound chests, and 20 colourable heraldic shields for the six factions. Cheap to vendor (≈700 KB total), MIT code; take `castle_tapestries` only after replacing its `unifieddyes` dependency.

*Not recommended:* **Natural Habitat** (GPL-2.0-only in-repo, undocumented media), **Asuna as a game** (AFL-1.1 inside; harvest individual submodules such as `naturalbiomes`/`cloudcraft`/`effervescence` instead), **Multidecor** (modern-only, wrong pixel density). **X Farming** and **Pixelfurniture** are both clean and worth using — but for crops/fish and small props respectively, not for the building kit itself.
