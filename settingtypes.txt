# Grudgelands — game settings shown in the main menu under "Games"
# (lua_api.md:198-201). Format per builtin/settingtypes.txt in the engine
# checkout (reference_projects/luanti):
# `name (Readable name) type type_args`, parts separated by exactly one space.
# Context annotations (`[server]` and friends) are valid only in builtin's own
# file and are INVALID here (builtin/settingtypes.txt:19-21).
#
# This file is read by the main menu, not by the server: each runtime default
# lives in the `core.settings:get_bool` call that reads its setting.

[Atmosphere]

#    The game's lighting presets: dynamic shadows, bloom, exposure and
#    saturation, sent to every player. Turn this off to keep the engine's own
#    lighting, for example to compare, or when a client's post-processing
#    misbehaves. Each player's render settings (Settings > Graphics) still
#    decide what their client draws; this switch only decides whether the
#    game asks for anything at all.
grug_atmosphere_enabled (Enable Grudgelands atmosphere presets) bool true

#    The sky, fog and light follow the region a player is in: one mood for
#    each people's lands (dwarf, human, elf, undead, orc, troll), plus
#    underground, the open ocean, the shared Battlegrounds and the two dragon
#    islands. The game looks at each player's region about every two seconds
#    and sends a change only when the mood changes.
#    With this off, admins can still pick a mood with /atmosphere, but nobody
#    is moved between them automatically.
#    Needs the setting above.
grug_atmosphere_zones (Drive the atmosphere from the player's zone) bool true

[Nameplates]

#    Colours of the name tags above creatures, guards, NPCs and players, one
#    pair per kind. Each value is an RGBA colour; the last byte sets the
#    opacity. Read when the server starts; restart after a change.
grug_nametag_aggressive_foreground (Aggressive nametag foreground) string #ff4b4b
grug_nametag_aggressive_background (Aggressive nametag background) string #00000040
grug_nametag_neutral_foreground (Neutral nametag foreground) string #ffd447
grug_nametag_neutral_background (Neutral nametag background) string #00000040
grug_nametag_guard_foreground (Guard nametag foreground) string #b76cff
grug_nametag_guard_background (Guard nametag background) string #00000040
grug_nametag_npc_foreground (NPC nametag foreground) string #d8c5ff
grug_nametag_npc_background (NPC nametag background) string #00000040
grug_nametag_player_foreground (Player nametag foreground) string #ffffff
grug_nametag_player_background (Player nametag background) string #00000040
grug_nametag_critter_foreground (Critter nametag foreground) string #ffffff
grug_nametag_critter_background (Critter nametag background) string #00000040

#    Show a small green health bar above injured aggressive and neutral
#    creatures and guards. It appears and disappears at the same distance as
#    their name tags.
grug_injured_mob_hp_bars (Show injured mob health bars) bool true

[World preparation]

#    Prepare the whole world before anyone can enter, instead of only the six
#    starting areas. This takes several hours. The progress counts finished
#    map tiles; mountains take longer. Afterwards only deep mining, building
#    or flying very high up and places outside the world's bounds are still
#    generated when someone gets there.
#    Read once, at the first start of a new world: changing it later does not
#    change that world. A normal shutdown keeps the progress for the next
#    start.
grug_prepare_full_world (Prepare full world before entry) bool false

#    (Developers) At every server start, check the ground under each building
#    plot of the capitals and log a warning where a plot no longer stands on
#    it (water, a drop or a rise beyond its limits). It changes nothing in the
#    world and adds a few seconds to the start.
grug_mapgen_terrain_audit (Log capital plot terrain findings at start) bool false

[World map]

#    Quality of the world map image shown on the Map tab, the same for every
#    player; the minimap always shows normal quality. normal: 1080x960 (about
#    6.7 nodes per pixel). high: 3600x3200 (2 nodes per pixel); its first
#    render at a world's start takes about a minute longer and clients
#    download about 8 MB instead of about 1 MB. The image is cached in the
#    world folder; changing the setting renders it again at the next start
#    and removes the tiles of the other quality.
grug_map_quality (World map quality) enum normal normal,high

[Combat]

#    Multiplier for all damage from creatures and NPCs, including damage over
#    time, auras and boss ground attacks. Damage from players and from the
#    environment stays the same. Read when the server starts; restart after a
#    change. 1.0 is the base damage.
grug_mob_damage_scale (Non-player attack damage multiplier) float 1.5 0 10

#    Scales the number of particles of the game's effects (skills, procs,
#    critical hits, shields, bosses and mob specials), the same for every
#    player. 1.0 is the designed amount; 0.5 halves it (every part of an
#    effect keeps at least one particle); 0 turns these effects' particles
#    off. Lifetimes and shapes stay. Read when the server starts; restart
#    after a change.
grug_particle_scale (Particle amount scale) float 1.0 0 2

[World life]

#    Trees and bushes grow back: around players, where the natural tree density
#    of a biome has been cut down, the game plants saplings of the species that
#    grow there, never within about 10 nodes of anything built or of farm soil.
#    The saplings then grow like any other sapling. Grass, ferns
#    and wild resource plants renew regardless of this switch.
grug_tree_regrowth (Regrow trees from saplings) bool true
