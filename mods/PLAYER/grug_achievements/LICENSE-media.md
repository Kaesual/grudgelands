## Cloak textures — painted by GPT-6 Astra (Round 33)

Own work painted for Grudgelands by GPT-6 Astra on 2026-10-04: hand-placed
pixel shapes in each cloak's approved palette, written with Pillow by
`tools/r33_c3/paint_cloaks.py` (Astra's script, kept as provenance; it writes
into its own `cloaks/` folder next to it). No image-generation service, no
third-party source images. The project dedicates any rights it holds in these
originals to CC0-1.0.

Format (character_visuals.md §5b): 32×32 RGBA, fully opaque; columns 0–15
the outer face seen from behind, columns 16–31 the lining seen from the front;
the outer face's 1-px border is the cloak's edge colour.
