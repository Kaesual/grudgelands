# Atlas direction marker media

`textures/grug_map_heading_{gold,cyan}_00.png` through `_15.png`: original
polygon artwork generated by `tools/r15_map/render_headings.py` for Grudgelands,
CC0-1.0. No third-party source images. Sixteen headings per colour, 32×32 RGBA.

# Housing Steward marker

`textures/grug_map_housing_steward.png`: original 16×16 RGBA pixel art (a
cottage and a gold key) drawn from a character grid by
`tools/r26_map/render_steward_icon.py` for Grudgelands, CC0-1.0. No
third-party source images.

# Minimap art (Round 27)

All generated by `tools/r27_minimap/render_icons.py` for Grudgelands,
CC0-1.0. No third-party source images.

- `textures/grug_map_quest_{available,locked,ready,active}.png`: original
  16×16 RGBA pixel art, a gold or grey "!" or "?" on a round dark badge.
- `textures/grug_map_innkeeper.png` (a tankard) and
  `textures/grug_map_home.png` (a gold-roofed house): original 16×16 RGBA
  pixel art drawn from character grids.
- `textures/grug_map_rim_cyan_00.png` through `_15.png`: original polygon
  artwork, 32×32 RGBA rim arrows in sixteen directions.
- `textures/grug_map_minimap_bezel.png`: original 256×256 RGBA opaque frame
  (bezel) of the round gliding minimap: a warm grey-bronze band with a fine
  light inner edge, dot marks at E, S and W and a small "N".

The minimap's round mask (`grug_map_minimap_mask.png`) is not shipped: the
server generates it at start (`grug_map/base.lua`, `mask_png`).
