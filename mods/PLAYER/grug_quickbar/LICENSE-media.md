# Media Origin & Licenses (grug_quickbar)

## Emote icons (Round 80)

Stills of the player model, rendered offline by
**`tools/r80_emote/icons.py`** (deterministic, `--check` holds the files to
it) from `mods/PLAYER/grug_visuals/models/grug_visuals_character.b3d` with the
repository's software renderer (`tools/r55_offhand/render.py`), in the
human's default look of `tools/r54_armor/data/skins/human_hair.png` (the
project's own CC0 1.0 skin). The model is derived from player_api's
`character.b3d` (CC BY-SA 3.0; `mods/BASE/player_api/license.txt`), so the
renders keep its licence. No third-party texture is drawn.
