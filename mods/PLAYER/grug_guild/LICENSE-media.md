# Media Origin & Licenses (grug_guild)

Made for Grudgelands by GPT-6 Astra (guild art drop 01, picked by the user on
2026-10-23): painted texel by texel by the drop's own script (`paint.py`, no
source images, no randomness, no image-generation model). Copied unchanged
under the `grug_guild_` prefix. The consumable icons are proposal P2
("Reading the rock"), the Miner's Remains overlay proposal P1 ("Lamplight
and tools"); the overlay is drawn over each tier rock's own tile at run time
(`items.lua`), so no stone pixels are bundled. The two status icons live in
`grug_core` with the other status icons.
