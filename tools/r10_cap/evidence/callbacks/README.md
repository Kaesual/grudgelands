not CAP completion: authored outer-room projection, exact rotated coordinates,
full-size animated-mesh clearance, textured views, six-capital integration and
the root-owned final PUC/LuaJIT pair remain pending.

fixtures under LuaJIT by calling each returned function with the absolute repo
root. `luajit.log` records real Riding callbacks, 14 inert node definitions,
24 mount appearance reload/duplicate leases, three gear display reloads, and
the real default furnace + profession extraction callback chain. The furnace
fixture verifies current-version VM activation, preserved inventory, cooking
timer, protected private positions, forged public position/node, distance,
unlearned Cooking and progression. These are bounded mocked-engine tests,
not screenshots or an actual engine persistence claim.

Production global writes are the established single mod-table declarations;
fixture globals are restored after execution. The sole sweep hit is an existing
comment in grug_mobs/init.lua. `fresh-server.log` passes. No PUC runtime was run.
The two fixtures are wired into the root-owned final runner; the historical
157-source R7 roster is unchanged.

The vendored furnace patch only changes the protection authorization seam.
Existing timers and the Cooking output extraction/progression wrappers remain
intact. Authored furnace sockets require a live nearby player and the actual
expected furnace node even if ordinary node protection happens to permit use.
