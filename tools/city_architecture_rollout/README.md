## Open and rebuild

`index.html` starts with four representative building forms, comparing the
previous transfer with the new framing. Culture buttons show the full catalog.
Each card opens the coupled
3D original/proposal comparison in `compare.html`. Filter by culture, search
for a town/building, or show only the seven cases with structural inspection
notes. The deferred placement rows and their reasons are listed below it.
The comparison works offline; the overview needs its adjacent capture files.

Rebuild the study only from a checkout of `48d69ef0`: its source hashes and
old-role assertions deliberately refer to the pre-integration templates. The
committed pages and captures still open directly in the current checkout. Do
not regenerate them from the adopted game templates. To verify adoption, use
[the integration proof](../r75_5_architecture/README.md).

```sh
python3 tools/city_architecture_rollout/build.py
python3 tools/city_architecture_rollout/check_structure.py
node tools/city_architecture_rollout/check_browser.mjs
python3 tools/city_architecture_rollout/overview.py
python3 -m http.server 8875 --bind 127.0.0.1 --directory tools/city_architecture_rollout
# With that server running in another terminal:
node tools/city_architecture_rollout/check_overview.mjs
```

Dependencies are the same as the original study: Python/Pillow, LuaJIT, the
local node registry, the pinned engine's blank texture, Node with built-in
WebSocket and Chromium. No remote assets or external service are required.

## Scope and method

The final pass contains **145 distinct template/palette comparisons**, including
all twelve exact reference scenes: 28 dwarf, 31 human, 22 elf, 26 orc, 21 troll
and 17 undead. Duplicate uses with the same template and palette binding share
a comparison; every actual placement row/count remains in the audit.
154 out-of-scope placement rows remain unchanged. This is a bounded pass over
the twelve layouts/rosters, not a claim about every structure generated by the
game. Conventional armourer workshops and stables are included even in military
districts; special barracks, guard towers and monumental compositions are not.

`rules.py` separates actual roof surfaces from interior canopy/step roles, then
reads outward-facing straight facade runs from the lowest occupied wall level.
Chimneys participate in the footprint but remain protected. Each run supplies
continuous, one-cell-wide piers in solid columns: openings cannot be overwritten
to force a regular bay. Intermediate piers divide long runs where space allows.
Ties follow the actual local roof heights. For asymmetric roofs, the higher side
wall remains a wall; only cells above the higher gable endpoint are gable infill.
The old `post`/`window_frame` label and coordinate modulo no longer decide the
frame. Upper open roof lanterns retain their explicit posts and beams.

Human and troll frames have a common low-eave belt plus the local higher roof
tie. Elf facades have one continuous serpentine belt at the common low-eave
height, including corners; higher ties are marble. Dwarf high side walls remain
masonry; only actual gable infill is wood. Other cultures use their accepted
materials on the same pier/tie/infill classification. Troll infill now trials
existing `grug_nodes:clay_band_umber` against dark junglewood, with the existing
platforms/stilts preserved. The two original troll references keep their bark.

All twelve reference scenes retain their exact committed deltas and remain
benchmarks. No per-building coordinate exceptions were added for the transfer.

The ordinary residential/utility distinction is intentionally small and
explicit. Houses, cottages, lodges and tenements use the residential profile;
trade/guild buildings use the utility profile. Human and elf roof bindings are
preserved. The initial all-earth pitched orc roofs were visually rejected by
the coordinator; final pitched orc roofs keep their existing red brick, while
flat roofs use the reviewed earth/red-rim combination. Existing low walls and
signature/parapet materials are not altered. Literal nodes, air, furniture,
lights, windows, doors, floor cells and under-floor stilts remain unchanged.

The data comes from the current worktree's actual templates and each placement's
main and channel palettes. Main advanced independently to `64d585f4`; relevant
templates, palettes and renderer inputs still match the study base `0fd00949`.
All source hashes and reference hashes are recorded, so later adoption must
recheck these instead of assuming that other agents have not changed them.

## Evidence

- `audit.json`: exact changes per scene, source and placement hashes, original
  and new node/param2 values, preserved geometry, excluded rows and preview-only
  reed definitions. This is an offline transfer artifact, not a runtime format.
- `catalog.json`: display metadata, reference links and inspection notes.
- `browser-check.json`: current comparison page hash, browser assertions and
  hashes of every screenshot. It checks all scenes and textures, paired camera
  movement/presets on a representative set and all structural exceptions,
  narrow layout, navigation, direct links and JavaScript errors.
- `captures/`: every proposal, paired screenshots for the references and seven
  structural notes, plus a mobile view.
- `contact_sheets/`: compact sheets used to visually inspect every proposal.
- `previous/`: four unchanged captures from `a4579cf1`, with a source/hash
  manifest, used only for the overview comparison.
- `structure-check.json`: checks decoded delivered scene cells, exact reference
  deltas and the reported defects (continuous thin posts/ties, masonry high
  walls, actual timber gables, troll clay and the continuous elf accent).
- `overview-check.json`: overview page and screenshot hashes; filters, image
  loading, card links, exclusion rows and mobile width checked through localhost.

Build assertions preserve cell keys, param2, drawtypes, node/collision boxes,
walkability and buildability. All changed cells must be facade/foundation/roof
roles; missing media and missing reference scenes fail the build. No shipped
source file is written. Browser/native renderer limitations and original asset
licensing are documented in the [reference study](../dwarf_architecture_study/README.md).

Current framing revision, 2026-11-11: 521 comparison assertions with 172
captures, 18 overview assertions, zero browser exceptions, and 14 grouped
structural checks over the delivered scenes. Python/Node syntax and Git
