Keep this archive separately if future high-resolution edits are needed.

From the repository root:

  python3 tools/map_icon_rework/build.py --check
  python3 tools/map_icon_rework/build.py
  python3 tools/map_icon_rework/review.py

--check verifies inventory, exact hashes, dimensions and alpha without writes.
The default build regenerates geometric sprites and checks all accepted PNGs;
it leaves illustrative masters unchanged. With the optional archive present,
--from-originals explicitly re-exports illustrations too and checks them
against the accepted hashes. No command silently fetches external originals.
Requirements: Python 3, Pillow; ImageMagick 7 with SVG support for exports.
A deliberate future artwork revision updates the acceptance manifest only
following visual approval; it is not refreshed by the build command.

The review page embeds all display images and links only to tracked assets.
Its old artwork is read from Git revision 0cb190ff, so regenerating the page
after integration preserves the before/after comparison. That history is
needed only to rebuild the report, not to view it or build the game.
