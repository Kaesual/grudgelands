Development uses LuaJIT. Run through an isolated read-only reference overlay
when this worktree's pinned reference directories are empty. Every returned
fixture accepts the absolute repository root; do not invoke it as a script and
then mistake an unused return value for a pass.

  registration and lifecycle, 68 stage bindings and fifteen mature/wild visual
  equalities. No wild timers, growing groups or shared mutable visual tables.

  tail; fifteen band/zone/host cases, protection/occupancy/shore negatives and
  seven native reef variants including kelp param2 and water-family checks.
- `writer_fixture.lua`: actual R6 private VM transaction for both cave plants,
  actual native-air/support preservation, guards, canonical replay and retained
  conditional setters. This larger writer fixture is a LuaJIT development check.
- `content_fixture.lua`: actual registration/semantic/resolver construction.
- `runtime_fixture.lua`: full real settlement palette and engine-shaped API for
  LuaJIT runtime assembly; it makes no world placement decisions.
- `derive_pins.lua REPO`: diagnostic mechanically derived constants followed by
  the real strict manifest constructor in a private in-memory source copy. It
  never edits live pins. Acceptance also requires the unchanged live constructor
  after the orchestrator installs the reviewed exact constants.

PUC/LuaJIT pair. No per-lane intermediate PUC process is authorized.
