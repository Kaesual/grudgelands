# Round 20 final POI gate

Run only once the coordinator freezes the round candidate. This is the bounded
LuaJIT-only real construction gate, not the portable PUC micro-KAT. It constructs
the production runtime/strict manifest from real MTS and the100-profile roster,
checks all70 new emitted compositions, and sends18 full-size planner owners
through the actual planner (two adjacent owners splitting each of nine authored
construction-family cores).
A captured settlement writer compares every emitted cell and preserves an actor
root sentinel. This is projection evidence, not a full VoxelManip population or
engine/visual acceptance claim. Successor source order remains terrain/world,
anchor activation, then authored settlements.

From the repository root, with an existing private output directory:

```sh
luajit tools/r20_pois/final_jit.lua "$PWD" /tmp/round20-pois-final
python3 tools/r20_pois/render.py /tmp/round20-pois-final
```

Use a five-minute external timeout for the final process and keep its complete
stdout/stderr. If it exceeds the bound, diagnose and report rather than expanding
into a world/seed certification suite. The runner does not launch other Lua or
engine processes. It writes15 selected actual-voxel TSVs and a70-row catalog;
the renderer creates a matching SVG/HTML gallery without loading the engine,
network, textures or a model. The views show footprints, heights and asymmetry
with schematic material colors; they cannot certify lighting or media appearance.

The gate checks emitted building counts, reachable interiors and two-node
entrances, full actor/host clearance, bounded palette registration and all70
anchor identities. Cooks and reused capital envoys additionally need the round's
integrated quest/socket registry check. GUI walking and appearance stay user-run.
