Artist's recommendation · Hammer C + Book E

A crowned head. A calm spread.

C's flared faces give the small hammer a strong outline, while E keeps enough page depth to read clearly at 16 px. D offers an asymmetric beaked head; F leans farther back. Both choices remain open.

Hammer CBook E
Read at 100% browser zoom. Each ground is shown in plain alpha and additive light, at actual 16, 32 and 64 CSS px. White, ivory and pale gold; bright edges, transparent gaps, a tight light halo. All four textures are 64 × 64 RGBA.
Bright-ground limit: additive light cannot darken snow. Near-white ground washes out the interior tones; the tests below deliberately show that loss. These are browser approximations, with no game tint applied.This browser uses screen blending as the fallback; it does not support plus-lighter.
