Priest · Smite / Final Word / Censure

Light with weight.

A hammer that strikes. A book that falls shut. Four luminous silhouettes, drawn to hold their shape in the middle of a fight.

Artist's recommendation

Hammer A + Book A

The flat hammer head reads fastest at 16 px. The closed book has the clearest page block and the quieter silhouette. Pick either symbol independently; A and B share the same light palette.

Hammer ABook A
Read at 100% browser zoom. Each ground is shown in plain alpha and additive light, at actual 16, 32 and 64 CSS px. White, ivory and pale gold; bright edges, transparent gaps, a tight light halo. All four source textures are 64 × 64 RGBA.
Bright-ground limit: additive light cannot darken snow. Near-white ground washes out the interior tones; the tests below deliberately show that loss. These are browser approximations, with no game tint applied.This browser uses screen blending as the fallback; it does not support plus-lighter.

Scale follows the existing effect catalogue preview: one size unit = 0.1 node. These are stills, not a timing or impact simulation. The existing rings and Final Word's column will be combined with the picked symbols by the FX lane; desktop and web acceptance follows in game.

Why 64 px? Both symbols keep simple shapes for the 16 px view; 64 px gives the larger falls smooth edges and room for the book's page block without extra ornament.
