# Media provenance

The twenty-four candidate textures are original pixel art by GPT-6 Astra,
painted by the committed [generator](generate.py). Their pixels, authored
maps and palettes are dedicated to [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
No downloads, imported pixels or recoloured existing textures are used in
the candidates. The generator/rendering code is GPL-3.0-or-later.
