# Round 75 functional displays

The focused fixture runs the engine-free display contract and checks that every
functional node is restored as itself by the existing claim-container reset
path.

Run from the repository root:

```sh
bash tools/r75_displays/run.sh
```

The lane is a compatible additive saved-state change. Round 75 as a whole needs
a map reset because its separately owned city dressing changes world generation;
the display nodes need no migration step.
