## Independent proof

`R8_NATIVE_BASELINE=1` disables the complete authored writer in the staged
comparison game. The probe sees the unchanged native-v7 nodes, reconstructs
the writer's owner-local lumen from the committed candidate and exclusion
bytes, applies the same first-64 target bound, flood-fills the native component,
and rejects sky contact, isolation and components smaller than 24 external
voxels. The normal branch run is a different fresh world. A mouth is counted
only when every exact lumen voxel from an eligible native proof is air there.

The negative controls reuse each already-generated native comparison world
without enabling the baseline setting for the second boot. Because its chunks
are already generated, the authored writer has never carved them. They report
0 carved and 0 connected despite 9 eligible candidates in seed 0 and 11 in
seed 1. Thus a writer that reaches no native cave is reported not connected.
