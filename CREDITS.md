# Credits

Grudgelands is built on the work of many people. This file collects the
credits for everything the game ships that someone else made. The exact
per-file record — file, author, source, licence and our changes — is the
`LICENSE-media.md` file next to the media in each mod (and `menu/`); vendored
code and its patches are in [VENDOR.md](VENDOR.md). Where this file and a
`LICENSE-media.md` row ever disagree, the row is right.

Grudgelands' own code is GPL-3.0-or-later ([LICENSE.txt](LICENSE.txt)); the
combined game is GPL-3.0-only because it includes GPL-3.0-only code from
cottages ([license overview](docs/research/licensing.md)). Media keep their
own licences.
